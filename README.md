# AutoEUDM

AutoEUDM is a local web tool I developed to speed up repetitive device-management workflows in EUDM.

It gives me one place to prepare, validate, review, and submit device deployments, returns, and location updates. It also handles ALM workbook imports and keeps unfinished work available between sessions.

AutoEUDM runs quietly in the background, can start when I log in, and can check for updates from a Git branch I choose.

The goal is simple: less manual entry, fewer avoidable mistakes, and a smoother workflow for the work I do every day.
